acs1_combined contains the American Community Survey 1 Year Estimates for the years between 2010 - 2019 and 2021 - 2025. acs1_combined DOES NOT CONTAIN DATA FOR 2020. Supplement 2020 data with the 2020 data from census_combined. This dataset only goes down to the county level.

acs5_combined contains the American Community Survey 5 Year Estimates for the 5 year spans of 2005-2009, 2010-2014, 2015-2019, 2020-2024. These spans should be treated as INDIVIDUAL DATA POINTS and not as 5 different datapoints. This dataset goes down to the subcounty level

census_combined contains Census information for the years 2000 and 2020. This dataset goes down to the subcounty level.
